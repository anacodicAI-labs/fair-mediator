# figdata/ubereats/

Earlier results on the Uber Eats Houston and Seattle catalogs with the 95 synthetic diners of
`data/shared/small_catalog/personas.json`, written by `scripts/c1_report.py` and the harness. The paper's
results use real Food.com diners and are in `figdata/ubereats-foodcom/` and `figdata/ubereats-*-foodcom/`.
Each CSV can be regenerated with the commands in `data/README.md`.
